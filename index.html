03 / Selected work

Research in practice.

A selection of projects that connect methodological questions with careful implementation and evaluation.

012025—present

Logical graphs for LLM uncertainty

Built a contradiction-aware graph over semantically clustered responses and propagated probabilities through it. The preprint reports improved uncertainty-based error detection over semantic entropy, particularly when sampled answers have meaningful logical structure.

LLM evaluation · PythonPreprint ↗
022026

Sparse FFN perturbation

Designed sparse Gaussian perturbations to intermediate feed-forward activations and tested whether the resulting instability provides an internal signal for factual recall and reasoning on Llama and Qwen models.

Model internals · PyTorch
032022—2024

Protein phosphorylation prediction

Combined ESM protein representations with a BiLSTM sequence model and integrated it with mass-spectrometry evidence from PTMiner. This work received a Beijing Outstanding Undergraduate Thesis award.

AI for science · Deep learning

04 / Open-source & engineering

Ideas built into usable tools.

Three projects where I made a concrete contribution, spanning uncertainty-aware reasoning, agent infrastructure, and data quality.

Research prototype01 / 03

UCRA

Uncertainty-guided cross-source response acquisition

Uses semantic uncertainty to decide when to consult an additional model, then combines answers with source-aware weighting. The repository provides a lightweight Python reference implementation, examples, and tests.

What it showsTurning an uncertainty estimate into an explicit, testable decision policy.
LLM uncertainty · PythonView repository ↗
Agent infrastructure02 / 03

lark-codex-bridge

A local Codex agent in Feishu / Lark chats

Connects chat messages to a local Codex CLI, with per-conversation sessions, streaming replies, file handling, workspace controls, and access settings. Adapted from an existing bridge architecture for a different agent runtime.

What it showsBuilding an end-to-end agent workflow with practical state and deployment concerns.
Agents · TypeScriptView repository ↗
Data-centric AI03 / 03

DataDoctor

Dataset quality checks for robot learning

A ForgeAI Robotics toolkit for inspecting LeRobot datasets. Building on the upstream lerobot-doctor project, I contributed a full-video audit that decodes frames and locates visual anomalies by frame and time interval.

What it showsConnecting dataset validation to reliable model-training workflows.
