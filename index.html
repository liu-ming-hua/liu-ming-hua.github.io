01 / Research focus

From uncertainty estimates to better decisions.

A useful confidence signal should tell us not only that a model may be wrong, but also when checking, clarifying, or deferring would improve the outcome.

01

Uncertainty in language models

Estimating uncertainty beyond surface-form variation by examining the logical relationships among possible answers.

Current research
02

Internal model signals

Testing whether perturbations to sparse feed-forward activations reveal instability in factual recall and reasoning.

Experimental work
03

World models & reliable agents

Interested in action-conditioned world models for evaluating and planning in embodied agents, and in uncertainty-aware checks when model predictions may be unreliable.

04 / Open-source & engineering

Ideas built into usable tools.

Four projects spanning robot-policy evaluation, uncertainty-aware reasoning, agent infrastructure, and data quality.

Featured · Robot learning evaluation01 / 04

VLAWorldEval

Connecting vision-language-action policies with action-conditioned world models

An open-source framework for closed-loop policy evaluation and recorded-action replay. It keeps model runtimes isolated, makes camera and action contracts explicit, and saves videos, metrics, and provenance together for reproducible analysis.

What it showsEngineering evaluation workflows that expose model assumptions and preserve the evidence needed to interpret results.
Robot learning · PythonView repository ↗
Research prototype02 / 04

UCRA

Uncertainty-guided cross-source response acquisition

Uses semantic uncertainty to decide when to consult an additional model, then combines answers with source-aware weighting. The repository provides a lightweight Python reference implementation, examples, and tests.

What it showsTurning an uncertainty estimate into an explicit, testable decision policy.
LLM uncertainty · PythonView repository ↗
Agent infrastructure03 / 04

lark-codex-bridge

A local Codex agent in Feishu / Lark chats

Connects chat messages to a local Codex CLI, with per-conversation sessions, streaming replies, file handling, workspace controls, and access settings. Adapted from an existing bridge architecture for a different agent runtime.

What it showsBuilding an end-to-end agent workflow with practical state and deployment concerns.
Agents · TypeScriptView repository ↗
Data-centric AI04 / 04

DataDoctor

Dataset quality checks for robot learning

A ForgeAI Robotics toolkit for inspecting LeRobot datasets. Building on the upstream lerobot-doctor project, I contributed a full-video audit that decodes frames and locates visual anomalies by frame and time interval.

What it showsConnecting dataset validation to reliable model-training workflows.
